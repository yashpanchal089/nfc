## 🚀 How to Host on GitHub Pages (Free)

This project has zero dependencies and uses standard static HTML5, CSS3, and JavaScript, making it 100% compatible with GitHub Pages, Vercel, Netlify, or any Apache/Nginx web server.

### Steps to Push to GitHub:

```bash
# 1. Initialize git in this directory
git init

# 2. Add all files
git add .

# 3. Commit files
git commit -m "Initial commit: Manasi Polyclinic Smart NFC Digital Card"

# 4. Link your GitHub repository
git remote add origin https://github.com/<YOUR_USERNAME>/<YOUR_REPOSITORY_NAME>.git

# 5. Push to main branch
git branch -M main
git push -u origin main
```

### Enable GitHub Pages:
1. Go to your GitHub repository -> **Settings** -> **Pages**.
2. Under **Branch**, select `main` (root) and click **Save**.
3. Your card will be live at `https://<YOUR_USERNAME>.github.io/<YOUR_REPOSITORY_NAME>/` or your custom domain (e.g. `card.manasipolyclinic.com`).

## 💳 How to Write/Program the NFC Card

You can write this card URL to any blank NTAG213 / NTAG215 / NTAG216 card using free smartphone apps:

1. Download **NFC Tools** from Google Play Store or Apple App Store.
2. Open the app and choose **Write** -> **Add a record**.
3. Select **URL / URI** and enter your deployed URL (e.g., `https://card.manasipolyclinic.com/`).
4. Tap **Write / 1 Byte** and hold the NFC card or card sticker to the back of your phone until it chirps "Write Complete!".
5. You're done! Now tapping the card on any modern phone will instantly open this digital card.
